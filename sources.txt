# Где брать конфиги. Этот файл вы правите, когда находите новые источники.
#
# Формат строки:
#   <url>[|WL|BL|WL-ALL]
#
# Метка в конце нужна для файлов, где конфиги для белых списков смешаны с обычными
# и различаются пометкой в имени: WL оставит только записи с [*CIDR] или [WL],
# BL — только с [BL]. Если файл целиком состоит из конфигов для белых списков и
# пометок в именах нет — ставьте WL-ALL. Для обычных однородных файлов метка не нужна.
#
# Что даёт пометка «белые списки»: такие конфиги публикуются отдельным файлом
# (configs/whitelist.txt) и не отсеиваются по скорости. Они работают там, где не
# работает ничего — на мобильном интернете с нулевым балансом, — и медленный сервер
# там лучше, чем никакого.
#
# Строки, начинающиеся с #, игнорируются — так можно временно отключить источник,
# не удаляя его.
#
# Формат самого файла-источника значения не имеет: обычный текст, base64, JSON —
# ссылки вытаскиваются из чего угодно.
